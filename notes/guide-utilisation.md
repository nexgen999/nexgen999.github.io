# Guide d'utilisation

Pour mettre à jour ce site avec votre propre contenu Obsidian :

1. **Copiez vos fichiers** : Placez vos dossiers et fichiers `.md` dans la racine ou un sous-dossier (comme `notes/`).
2. **Éditez `navigation.md`** : Listez les fichiers dans l'ordre souhaité.
3. **Poussez sur GitHub** : GitHub Pages fera le reste !

## Syntaxe supportée
- Listes
- Tableaux
- Images
- Blockquotes
