# Bienvenue dans votre Vault Web

Ceci est une reproduction de l'expérience **Obsidian** directement dans votre navigateur.

## Caractéristiques
- 🚀 **Statique** : Hébergé sur GitHub Pages sans backend.
- 🎨 **Design Premium** : Inspiré du thème sombre d'Obsidian.
- 📂 **Structure Flexible** : Contrôlée par `navigation.md`.
- 💻 **Code Highlighting** : Support de Prism.js pour vos extraits de code.

### Exemple de code
```javascript
function helloWorld() {
  console.log("Bonjour Obsidian !");
}
```

> [!TIP]
> Vous pouvez ajouter de nouveaux fichiers dans le dossier `notes/` et les lister dans `navigation.md`.
